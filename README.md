# smartteacher-web

L'hôte statique du lecteur web de SmartTeacher (https://github.com/SmartAudioTools : dépôt SmartTeacher, `QCM/web/`) :
la page des élèves (`index.html`, qui envoie ses appels à Google Apps Script) et les fichiers qu'elle importe (`lecteur_qt.js`, `qtpy6web.js`, `lecteur.zip`,
la roue serializejson). Publié par GitHub Pages depuis la branche `main`, mis à jour par
`QCM/web/deployer.sh` à chaque déploiement : rien n'est édité à la main ici.
